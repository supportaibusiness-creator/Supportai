# SupportAI MVP

Step 1 MVP for a global AI customer-support SaaS.

## What works

- Responsive landing page
- Product positioning
- Pricing section
- Working demo chat UI
- Demo responses for common questions
- No paid API required

## Run locally

Install Node.js 20+.

```bash
npm install
npm run dev
```

Open http://localhost:3000
